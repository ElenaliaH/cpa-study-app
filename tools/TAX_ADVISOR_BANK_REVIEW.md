## 生成与验证

在项目根目录执行（python需可用，转换只使用标准库）：

```powershell
python tools/build-tax-advisor-bank.py
python tools/build-tax-advisor-bank.py --check
node tests/tax-advisor-bank.test.js
npm start
node tests/tax-advisor-browser.test.js
npm test
npm run test:workspaces
npm run test:workspaces:browser
```

浏览器测试需要 Playwright 和本机 Edge；依赖在 Codex 运行时中时需设置对应 NODE_PATH。测试使用独立浏览器上下文并拦截非本地网络，不操作用户真实登录或学习数据。

输出位于 `work/tax-advisor-bank/`：每科包含 publishable（预览题库）、corrected-source（修正源数据副本）、audit（修改前后记录）。目录已忽略，不会被普通 git add 自动提交。publishable 文件名仅为兼容现有题库格式，不表示已经发布。

预览服务器仅开放两份 publishable JSON，不开放原始PDF、ZIP、修正源副本和审校记录。

## 用户验收

1. 打开 `http://127.0.0.1:3000/?taxDemo=1&workspacePreview=1`。
2. 切换到“税务师备考”，进入“题库练习”。
3. 选择“税法一”或“税法二”，检查章节、顺序/随机练习和单选/多选提交。
4. 答题后刷新、切换另一科再切回，确认答题卡及继续练习位置保留。
5. 为题目添加收藏、笔记，确认另外一科和CPA中不出现这些记录。
6. 在增值税章节原题204检查公共材料和4个小问。
7. 用手机宽度检查长题干、选项、答题卡；本机127.0.0.1地址不能直接供另一台手机访问。
